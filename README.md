# GuideLines

GuideLines is a lightweight Chrome extension for adding Figma-style rulers and draggable guides to any webpage.

It helps designers and developers inspect layout, alignment, spacing, and distances directly in the browser.

## Features

* Horizontal and vertical rulers
* Draggable guide lines
* Precise keyboard nudging
* Guide-to-element measurements
* Guide-to-guide measurements
* Persistent guides per page
* Lightweight, framework-free implementation

## Shortcuts

* `Alt + Shift + R` — Toggle GuideLines
* `Esc` — Deselect the selected guide
* `Delete` — Delete the selected guide
* Arrow keys — Move the selected guide by 1px
* `Shift + Arrow` — Move the selected guide by 8px
* Hold `Alt` and hover — Measure from the selected guide
